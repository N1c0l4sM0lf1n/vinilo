# 🎵 Colección de Vinilos (POO)

Proyecto en **Java** que implementa un mantenedor de vinilos utilizando los principios de **Programación Orientada a Objetos (POO)** y **Responsabilidad Única (SRP)**.

---

## 🚀 Funcionalidades
- Agregar nuevos vinilos (artista, disco, año)
- Buscar vinilos por artista
- Mostrar todos los vinilos de la colección
- Ver cantidad total de vinilos
- Mostrar espacios disponibles (máximo 100)

---

## 🧩 Clases
### `Vinilo`
Representa un vinilo con sus atributos básicos.

### `ColeccionVinilos`
Administra la lista de vinilos: agrega, busca y muestra la colección.

### `Main`
Clase principal que ejecuta el programa.
